## 1. Methodology (reproducible)

**Universe.** 134 liquid US large/mid-cap names across tech, semis, financials, healthcare, industrials, consumer, energy, and crypto-adjacent (full list in the dataset).

**Data.** Daily adjusted close prices, ~2 years, from Yahoo Finance (`yfinance`).

**Factors (computed per name):**

| Factor | Definition |
|---|---|
| `ret_1m` | 1-month return (21 trading days) |
| `ret_3m` | 3-month return (63 trading days) |
| `ret_6m` | 6-month return (126 trading days) |
| `ret_12m` | 12-month return (252 trading days) |
| `momentum_z` | Equal-weight z-score of the four return horizons |
| `vol_12m` | Annualized realized volatility (63-day window) |
| `maxdd_12m` | Maximum drawdown from peak over the trailing window |
| `quality_z` | 0.5·(−z(vol)) + 0.5·(−z(maxdd)) |
| `composite` | 0.6·momentum_z + 0.4·quality_z |

**Composite score.** Each component is cross-sectionally z-scored, then combined:

```
composite = 0.6 * z(momentum) + 0.4 * z(quality)
```

A higher composite score indicates stronger multi-horizon momentum and better risk-adjusted performance (lower volatility, shallower drawdowns).
